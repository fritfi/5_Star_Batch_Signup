# 5_Star_Batch_Signup
My school uses a 5-Star website that allows students to sign up for "SUCCESS" Sessions every day (Basically a period where you can choose what class you need extra help on OR extra lunch). The ISSUE is that the default is Quiet Study Hall, which is basically the equivalent of detension. If you forget to sign up, you get sent to the trenches of QSH. The second issue is there is no batch select, to sign up for a bunch of days at once. This means that you have to go through like three different confirmation buttons to sign up for one single day, and repeat this for days on weeks on months. Terrible. I was fed up, so I made a TypeMonkey script that batch selects Off Campus (Extra lunch) instead!


To USE THIS, Download the TamperMonkey Extension off the Chrome Web Store, add a new userscript, and import the Java Code. When you open your Flex Sign up, you'll see a blue button on the bottom right, click it and it will autosign up all avaliable days.
